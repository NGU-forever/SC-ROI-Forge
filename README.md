# SC-ROI-Forge

面向 **Star Citizen** 的 ROI（Region of Interest）可视化标定工具。

本项目从 Star Citizen HUD Overlay 的开发实践中获得启发，聚焦游戏画面中关键 HUD / 界面区域的兴趣区标定、可视化与迭代，为后续 overlay、检测与交互能力提供可复用的标定基础。

## 目标

- 在游戏画面或截图上标定 ROI 区域
- 可视化 ROI 边界、标签与层级关系
- 支持标定结果的保存、加载与迭代调整
- 为 Star Citizen 相关 HUD Overlay 开发提供可验证的兴趣区数据

## 背景

Star Citizen 的座舱与 HUD 信息密度高、布局随模式变化。Overlay 能力依赖对屏幕关键区域的准确定位。SC-ROI-Forge 将「标定」独立成工具链环节：先把 ROI 画清楚、对得准，再服务上层 overlay 与逻辑开发。

## 状态

项目处于早期搭建阶段。文档与工具能力将随开发持续补充。
