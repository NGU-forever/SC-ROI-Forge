# SC-ROI-Forge

面向 **Star Citizen** 的 ROI（Region of Interest）可视化标定工具。

本项目从 Star Citizen HUD Overlay 的开发实践中获得启发，聚焦**屏幕画面**上关键 HUD / 界面区域的兴趣区标定与可视化，主要为后续 **OCR**、模板匹配、目标检测等**纯视觉方案**提供可复用的标定基础。

## 合规边界（重要）

本项目**仅服务于基于屏幕画面的视觉方案**（如截图 / 录屏上的 OCR、ROI 裁剪、检测与 overlay 标定）。

**不涉及、也不支持**以下行为：

- 读取游戏进程内存或内部数据结构
- 内存注入、DLL 注入、钩子（hook）或进程篡改
- 逆向工程游戏客户端以获取未公开数据
- 任何绕过官方客户端、修改游戏文件或干扰反作弊机制的做法

所有输入均来自用户提供的**图像 / 视频帧**（或等价的屏幕捕获画面），输出仅为 ROI 标定与可视化结果。

## 目标

- 在游戏截图或屏幕画面上标定 ROI 区域
- 可视化 ROI 边界、标签与层级关系
- 支持标定结果的保存、加载与迭代调整
- 为 OCR 等视觉管线提供可验证的兴趣区布局数据

## 背景

Star Citizen 的座舱与 HUD 信息密度高、布局随模式变化。基于视觉的 overlay / OCR 能力依赖对屏幕关键区域的准确定位。SC-ROI-Forge 将「标定」独立成工具链环节：先把 ROI 画清楚、对得准，再服务上层纯视觉处理，而不触碰游戏内部数据。

## 状态

项目处于早期搭建阶段。文档与工具能力将随开发持续补充。
