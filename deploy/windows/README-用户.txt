SC-ROI Forge — 使用说明（给玩家）

1. 解压整个文件夹（不要只拷一个文件）。
2. 第一次：双击「安装并启动.bat」
   - 若提示安装 WebView2：按打开的网页装好，再双击一次。
   - 会尝试在桌面创建快捷方式。
3. 以后：双击「SC-ROI-Forge.exe」或「启动.bat」或桌面快捷方式即可。

不需要安装 Node、Python、Rust。

常见问题：
- 防火墙询问：请允许本地网络（程序只连本机 127.0.0.1）。
- 杀软误报：把本文件夹加入信任区后再开。
- 提示端口被占用：关掉其它占用 8000 端口的程序，或重启电脑后再开。

画框、导出不需要联网。AI 建议需要你在软件里自己填写 API Key。
